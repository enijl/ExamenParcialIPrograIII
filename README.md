# Proyecto: Árboles Binarios y Control de Ejecuciones del Thread

## 🌳 Árboles Binarios
Un **árbol binario** es una estructura de datos donde cada nodo tiene como máximo dos hijos: uno izquierdo y uno derecho.  
Se usa en algoritmos de búsqueda, estructuras jerárquicas y recorridos como:

- Inorden (izquierda → raíz → derecha)
- Preorden (raíz → izquierda → derecha)
- Postorden (izquierda → derecha → raíz)

## 🧵 Control de Ejecuciones del Thread
El **control de ejecución de hilos (threads)** permite manejar procesos simultáneos en una aplicación.  
Incluye funciones como:

- `start()` para iniciar el hilo
- `sleep()` para pausarlo temporalmente
- `interrupt()` o banderas para detenerlo
- Uso de `synchronized` o `locks` para evitar condiciones de carrera
